# OmniTech — Space Map JSON API

`assets/omnitech/space_map.json` is the single source of truth for everything
space-related in OmniTech: which bodies exist, how they look in the GUI and sky,
what dimension they map to, how far away they are, and what fuel it costs to
reach them.

This document is the complete authoring reference for the file.

## 1. File Location

```
src/main/resources/assets/omnitech/space_map.json
```

The file is loaded at runtime (client-side) by `SpaceMapLoader` using
`ResourceManager`. It is NOT generated by data generators — edit it directly.

---

## 2. Top-Level Structure

```json
{
  "galaxies": [ <Galaxy>, ... ]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `galaxies` | array of Galaxy | yes | All galaxies in the universe |

---

## 3. Galaxy Object

```json
{
  "id": "milky_way",
  "texture": "omnitech:textures/space/galaxy/milky_way.png",
  "background": "omnitech:textures/space/background/milky_way.png",
  "orbital_radius": 220,
  "orbital_speed": 0.87,
  "star_systems": [ <StarSystem>, ... ]
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | string | yes | — | Unique identifier. Used in lang keys: `omnitech.space.galaxy.<id>` |
| `texture` | string | yes | — | Texture shown as the galaxy body in the GUI |
| `background` | string | no | none | Full-screen background when browsing this galaxy's systems |
| `orbital_radius` | int | no | 180 | Orbit radius in GUI pixels at zoom = 1.0 |
| `orbital_speed` | float | no | 0 | Speed multiplier (0 = Kepler fallback) |
| `star_systems` | array | yes | [] | Star systems within this galaxy |

---

## 4. StarSystem Object

```json
{
  "id": "sol",
  "texture": "omnitech:textures/space/star/sun.png",
  "background": "omnitech:textures/space/background/sol.png",
  "orbital_radius": 140,
  "orbital_speed": 1.71,
  "size": 109.0,
  "bodies": [ <CelestialBody>, ... ]
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | string | yes | — | Unique identifier. Lang key: `omnitech.space.system.<id>` |
| `texture` | string | yes | — | Texture shown as the star in the GUI and sky |
| `background` | string | no | none | Background shown when browsing this system's planets |
| `orbital_radius` | int | no | 180 | Orbit radius in galaxy-level GUI at zoom = 1.0 |
| `orbital_speed` | float | no | 0 | Speed multiplier inside the galaxy view (0 = Kepler fallback) |
| `size` | float | no | 0 | Star diameter in Earth-diameter units (Sol = 109.0). Used by the sky renderer to scale the star disc. `0` defaults to Sol. |
| `bodies` | array | yes | [] | Planets (and their moons) in this system |

## 5. CelestialBody Object

Used for both **planets** and **moons**. The `type` field distinguishes them.

```json
{
  "id": "earth",
  "type": "planet",
  "dimension": "minecraft:overworld",
  "texture": "omnitech:textures/space/planet/earth.png",
  "background": "omnitech:textures/space/background/earth.png",
  "orbital_radius": 155,
  "orbital_speed": 1.47,
  "size": 1.0,
  "orbital_distance_km": 149598000,
  "orbital_inclination": 0.00,
  "ascending_node": 174.87,
  "moons": [ <CelestialBody>, ... ]
}
```

```json
{
  "id": "moon",
  "type": "moon",
  "dimension": "omnitech:moon",
  "texture": "omnitech:textures/space/moon/moon.png",
  "orbital_radius": 90,
  "orbital_speed": 3.31,
  "size": 0.27,
  "parent_distance_km": 384400,
  "orbital_inclination": 5.14,
  "ascending_node": 125.08,
  "moons": []
}
```

### Field Reference

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `id` | string | yes | — | Unique identifier. Lang key: `omnitech.space.body.<id>` |
| `type` | string | yes | — | `"planet"` or `"moon"` |
| `dimension` | string | no | null | Minecraft dimension ID. `null` means no playable dimension yet. |
| `texture` | string | yes | — | Texture shown in GUI and sky |
| `background` | string | no | none | Background shown in GUI when browsing this planet's moons |
| `orbital_radius` | int | no | 120 | GUI orbit radius in pixels at zoom = 1.0 |
| `orbital_speed` | float | no | 0 | GUI animation speed multiplier (0 = Kepler fallback) |
| `size` | float | no | 0 | Diameter relative to Earth (Earth = 1.0). Used for sky scaling. |
| `orbital_distance_km` | long | no | 0 | **Planets only.** Distance from the star in km. Required for accurate fuel costs and sky scaling. |
| `parent_distance_km` | long | no | 0 | **Moons only.** Distance from parent planet in km. Required for accurate fuel costs and sky scaling. |
| `orbital_inclination` | float | no | 0 | Orbital plane tilt in degrees from the ecliptic. See §9. |
| `ascending_node` | float | no | 0 | Longitude of ascending node in degrees. See §9. |
| `moons` | array | no | [] | Child moons (for planets) or empty (for moons). |

> **Deprecated field:** `fuel_cost` (int) is kept for JSON backwards-compatibility
> but is ignored at runtime. Dynamic calculation from `orbital_distance_km` /
> `parent_distance_km` supersedes it. Do not add it to new entries.

## 6. Texture Paths

All textures referenced in `space_map.json` must use the full resource-location
path format:

```
<namespace>:textures/space/<category>/<filename>.png
```

**Namespace:** Use `omnitech` for OmniTech assets.

**Categories and expected paths:**

| Category | Path | Used for |
|----------|------|---------|
| Galaxy | `textures/space/galaxy/<id>.png` | Galaxy body in GUI |
| Star | `textures/space/star/<id>.png` | Star body in GUI and sky |
| Planet | `textures/space/planet/<id>.png` | Planet in GUI and sky |
| Moon | `textures/space/moon/<id>.png` | Moon in GUI and sky |
| Background | `textures/space/background/<id>.png` | Full-screen background in GUI |

**Example:**
```
omnitech:textures/space/planet/earth.png
↓  (sky renderer converts to atlas sprite ID)
omnitech:space/planet/earth
```

Textures are automatically registered in the celestials atlas via:
```
assets/minecraft/atlases/celestials.json
```

Any `.png` placed under `assets/omnitech/textures/space/` will be picked up
automatically. No additional registration is required.

## 7. Orbital Parameters

### `orbital_radius`

Controls the visual orbit radius in the GUI orrery, in pixels at zoom = 1.0.
This does **not** affect the sky renderer.

| Scale | Typical value |
|-------|--------------|
| Inner planet | 80–120 |
| Middle planet | 140–200 |
| Outer planet | 290–490 |
| Moon (around parent) | 70–135 |

### `orbital_speed`

A multiplier applied to the base orbital speed for GUI animation:

```
angular_velocity = ORBIT_SPEED × orbital_speed
```

where `ORBIT_SPEED = 2π / 30,000 rad/ms`.

If `orbital_speed = 0`, the Kepler fallback is used:

```
angular_velocity = ORBIT_SPEED × (200 / orbital_radius)^1.5
```

**Suggested values (relative, not physically accurate):**

| Body | Suggested |
|------|-----------|
| Inner planet (fast) | 2.0 – 4.0 |
| Earth-like | 1.47 |
| Outer planet (slow) | 0.3 – 0.6 |
| Close moon | 3.0 – 5.0 |
| Distant moon | 1.5 – 2.5 |

## 8. Distance & Fuel System

### Why these fields matter

`orbital_distance_km` and `parent_distance_km` feed two systems:

1. **Fuel cost calculation** — `TravelDistanceCalculator.fuelCostMb()`
2. **Sky scaling** — apparent angular size of bodies in the sky renderer

Setting both fields accurately for any body that has or may have a playable
dimension is strongly recommended.

### Planets: `orbital_distance_km`

The semi-major axis distance from the star, in kilometres. For the Sol system,
real values from NASA:

| Planet | `orbital_distance_km` |
|--------|-----------------------|
| Mercury | 57,909,000 |
| Venus | 108,209,000 |
| Earth | 149,598,000 |
| Mars | 227,939,000 |
| Jupiter | 778,299,000 |
| Saturn | 1,429,394,000 |
| Uranus | 2,870,990,000 |
| Neptune | 4,498,252,000 |

For custom/fictional planets, choose a value that places the planet at an
appropriate distance to give a reasonable fuel cost.

### Moons: `parent_distance_km`

The distance from the moon to its parent planet, in kilometres.

| Moon | Parent | `parent_distance_km` |
|------|--------|----------------------|
| Moon | Earth | 384,400 |
| Io | Jupiter | 421,700 |
| Europa | Jupiter | 671,100 |
| Ganymede | Jupiter | 1,070,400 |
| Titan | Saturn | 1,221,870 |

### Fuel Formula

```
distance_km = escape_cost + |fromStarDist − toStarDist| + entry_cost

fuel_mB     = 560 + 39 × √(distance_km / 384,400)
```

| Term | Value when |
|------|-----------|
| `escape_cost` | `moon.parent_distance_km` if departing from a moon, else `0` |
| `entry_cost` | `target.parent_distance_km` if target is a moon, else `0` |

## 9. Inclination & Ascending Node

Orbital inclination tilts a body's orbital plane away from the ecliptic (the
plane of Earth's orbit). The ascending node determines the compass direction of
that tilt.

### `orbital_inclination`

Degrees from 0 to 90. `0` = exactly in the ecliptic plane.

In the sky renderer:
```java
poseStack.mulPose(Axis.ZP.rotationDegrees(orbital_inclination));
```

### `ascending_node`

Longitude of the ascending node (Ω), in degrees 0–360. Determines which
direction in the ecliptic plane the tilt points toward.

In the sky renderer:
```java
poseStack.mulPose(Axis.YP.rotationDegrees(ascending_node));
// then:
poseStack.mulPose(Axis.ZP.rotationDegrees(orbital_inclination));
```

### Real Solar System Values

| Body | `orbital_inclination` | `ascending_node` |
|------|-----------------------|------------------|
| Mercury | 7.00 | 48.33 |
| Venus | 3.39 | 76.68 |
| Earth | 0.00 | 174.87 |
| Moon | 5.14 | 125.08 |
| Mars | 1.85 | 49.57 |
| Jupiter | 1.30 | 100.49 |
| Io | 0.04 | 43.98 |
| Europa | 0.47 | 219.06 |
| Ganymede | 0.20 | 63.55 |
| Saturn | 2.49 | 113.67 |
| Titan | 0.35 | 28.06 |
| Uranus | 0.77 | 74.01 |
| Neptune | 1.77 | 131.78 |

For fictional bodies, any values in the realistic ranges above will produce
plausible results. Use `0` for both fields to place a body exactly in the
ecliptic.

## 10. Localisation

Every `id` in the space map should have a corresponding translation key in
`assets/omnitech/lang/en_us.json`:

```json
{
  "omnitech.space.galaxy.milky_way":  "Milky Way",
  "omnitech.space.galaxy.andromeda":  "Andromeda",
  "omnitech.space.system.sol":        "Sol",
  "omnitech.space.system.tau_ceti":   "Tau Ceti",
  "omnitech.space.body.earth":        "Earth",
  "omnitech.space.body.moon":         "Moon",
  "omnitech.space.body.europa":       "Europa"
}
```

If a key is missing, the raw key string is displayed in the GUI.

## 11. Adding a New Planet

1. **Add the texture** to `assets/omnitech/textures/space/planet/<id>.png`.

2. **Add the entry** to `space_map.json` inside the appropriate star system's
   `"bodies"` array:

```json
{
  "id": "kepler_22b",
  "type": "planet",
  "dimension": null,
  "texture": "omnitech:textures/space/planet/kepler_22b.png",
  "orbital_radius": 170,
  "orbital_speed": 1.20,
  "size": 2.4,
  "orbital_distance_km": 117000000,
  "orbital_inclination": 2.80,
  "ascending_node": 90.0,
  "moons": []
}
```

3. **Add a lang key** in `en_us.json`:

```json
"omnitech.space.body.kepler_22b": "Kepler-22b"
```

4. **If the planet has a playable dimension**, set `"dimension"` to its
   Minecraft dimension ID and create the dimension type JSON with:

```json
{
  "neoforge:custom_skybox": "omnitech:space_sky"
}
```

## 12. Adding a New Star System

1. Add textures for the star and its background.

2. Add the star system to the target galaxy's `"star_systems"` array:

```json
{
  "id": "barnards_star",
  "texture": "omnitech:textures/space/star/barnards_star.png",
  "background": "omnitech:textures/space/background/barnards_star.png",
  "orbital_radius": 280,
  "orbital_speed": 0.55,
  "size": 19.3,
  "bodies": [
    {
      "id": "barnards_b",
      "type": "planet",
      "dimension": null,
      "texture": "omnitech:textures/space/planet/barnards_b.png",
      "orbital_radius": 130,
      "orbital_speed": 1.90,
      "size": 3.2,
      "orbital_distance_km": 9500000,
      "orbital_inclination": 4.10,
      "ascending_node": 155.0,
      "moons": []
    }
  ]
}
```

3. Add lang keys for the system and all its bodies.

## 13. Adding a New Galaxy

Add a new entry to the top-level `"galaxies"` array:

```json
{
  "id": "triangulum",
  "texture": "omnitech:textures/space/galaxy/triangulum.png",
  "background": "omnitech:textures/space/background/triangulum.png",
  "orbital_radius": 160,
  "orbital_speed": 0.60,
  "star_systems": []
}
```

Add a lang key: `"omnitech.space.galaxy.triangulum": "Triangulum Galaxy"`.

## 14. Full Schema Reference

```
root
└── galaxies[]
    ├── id                  string   (required)
    ├── texture             string   (required)  full resource path
    ├── background          string   (optional)  full resource path
    ├── orbital_radius      int      (optional, default 180)
    ├── orbital_speed       float    (optional, default 0 → Kepler)
    └── star_systems[]
        ├── id              string   (required)
        ├── texture         string   (required)
        ├── background      string   (optional)
        ├── orbital_radius  int      (optional, default 180)
        ├── orbital_speed   float    (optional, default 0 → Kepler)
        ├── size            float    (optional, default 0 → Sol=109)
        └── bodies[]                              ← planets
            ├── id                  string   (required)
            ├── type                string   (required)  "planet" | "moon"
            ├── dimension           string   (optional)  null = not implemented
            ├── texture             string   (required)
            ├── background          string   (optional)
            ├── orbital_radius      int      (optional, default 120)
            ├── orbital_speed       float    (optional, default 0 → Kepler)
            ├── size                float    (optional, default 0)
            ├── orbital_distance_km long     (planets: km from star)
            ├── parent_distance_km  long     (moons: km from parent planet)
            ├── orbital_inclination float    (optional, default 0°)
            ├── ascending_node      float    (optional, default 0°)
            └── moons[]                              ← same schema as bodies[]
```
