# OmniTech — Space Map API

Celestial bodies are defined as individual JSON files in:

```
src/main/resources/assets/omnitech/celestial_bodies/
```

Each file defines **one body** — a galaxy, star, planet, or moon — using a flat
`{ uuid, parent, type, ... }` structure. The loader (`SpaceMapLoader`) reads all
`*.json` files in that directory at runtime and reconstructs the
Galaxy → StarSystem → CelestialBody hierarchy in memory.

This file is the complete authoring reference.

## 1. File Location & Naming

```
src/main/resources/assets/omnitech/celestial_bodies/<uuid>.json
```

Name the file after the body's UUID (e.g. `earth.json`, `sol.json`).

Files are **not** generated by data generators — edit them directly.

---

## 2. Body Schema

Every file shares the same top-level shape:

```json
{
  "uuid":   "earth",
  "parent": "sol",
  "type":   "planet",
  ...body-specific fields...
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `uuid` | string | yes | Unique identifier. Used as the lang key base and as a `parent` target for child bodies. |
| `parent` | string | yes | UUID of the parent body, or `"root"` for galaxies. |
| `type` | string | yes | `"galaxy"` \| `"star"` \| `"planet"` \| `"moon"` |

---

## 3. Hierarchy via `uuid` / `parent`

```
"root"
 └── galaxy   (parent = "root")
      └── star     (parent = galaxy.uuid)
           └── planet   (parent = star.uuid)
                └── moon     (parent = planet.uuid)
```

Bodies are sorted automatically:
- Planets within a system — ascending `orbital_distance_km`
- Moons around a planet — ascending `parent_distance_km`
- Star systems within a galaxy — ascending `orbital_radius`
- Galaxies — ascending `orbital_radius`

## 4. Galaxy

```json
{
  "uuid": "milky_way",
  "parent": "root",
  "type": "galaxy",
  "texture": "omnitech:textures/space/galaxy/milky_way.png",
  "background": "omnitech:textures/space/background/milky_way.png",
  "orbital_radius": 220,
  "orbital_speed": 0.87
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `texture` | string | — | Texture shown as the galaxy body in the GUI |
| `background` | string | none | Full-screen background when browsing this galaxy's systems |
| `orbital_radius` | int | 120 | Orbit radius in GUI pixels at zoom = 1.0 |
| `orbital_speed` | float | 0 | Speed multiplier (0 = Kepler fallback) |

## 5. Star

```json
{
  "uuid": "sol",
  "parent": "milky_way",
  "type": "star",
  "texture": "omnitech:textures/space/star/sun.png",
  "background": "omnitech:textures/space/background/sol.png",
  "orbital_radius": 140,
  "orbital_speed": 1.71,
  "size": 109.0
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `texture` | string | — | Texture shown as the star in the GUI and sky |
| `background` | string | none | Background shown when browsing this system's planets |
| `orbital_radius` | int | 120 | Orbit radius in galaxy-level GUI at zoom = 1.0 |
| `orbital_speed` | float | 0 | Speed multiplier (0 = Kepler fallback) |
| `size` | float | 0 | Star diameter in Earth-diameter units (Sol = 109.0). `0` defaults to Sol. |

## 6. Planet

```json
{
  "uuid": "earth",
  "parent": "sol",
  "type": "planet",
  "dimension": "minecraft:overworld",
  "texture": "omnitech:textures/space/planet/earth.png",
  "background": "omnitech:textures/space/background/earth.png",
  "orbital_radius": 155,
  "orbital_speed": 1.47,
  "size": 1.0,
  "orbital_distance_km": 149598000,
  "orbital_inclination": 0.0,
  "ascending_node": 174.87,
  "base_temperature": 15.0,
  "temperature_amplitude": 10.0,
  "surface_pressure": 101325.0,
  "pressure_gradient": 12.0,
  "surface_y": 64
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `dimension` | string | null | Minecraft dimension ID. `null` means no playable dimension yet. |
| `texture` | string | — | Texture shown in GUI and sky |
| `background` | string | none | Background shown in GUI when browsing this planet's moons |
| `orbital_radius` | int | 120 | GUI orbit radius in pixels at zoom = 1.0 |
| `orbital_speed` | float | 0 | GUI animation speed multiplier (0 = Kepler fallback) |
| `size` | float | 0 | Diameter relative to Earth (Earth = 1.0). Used for sky scaling. |
| `orbital_distance_km` | long | 0 | Distance from the star in km. Required for fuel costs and sky scaling. |
| `orbital_inclination` | float | 0 | Orbital plane tilt in degrees from the ecliptic. |
| `ascending_node` | float | 0 | Longitude of ascending node in degrees. |
| `base_temperature` | double | 20.0 | Surface temperature in °C at noon. |
| `temperature_amplitude` | double | 0.0 | Half-amplitude of the day/night temperature swing in °C. |
| `surface_pressure` | double | 101325.0 | Atmospheric pressure in Pa at `surface_y`. |
| `pressure_gradient` | double | 12.0 | Pressure rise per block of depth (Pa/block). |
| `surface_y` | int | 64 | Reference Y level for pressure calculations. |

## 7. Moon

```json
{
  "uuid": "moon",
  "parent": "earth",
  "type": "moon",
  "dimension": "omnitech:moon",
  "texture": "omnitech:textures/space/moon/moon.png",
  "orbital_radius": 90,
  "orbital_speed": 3.31,
  "size": 0.27,
  "parent_distance_km": 384400,
  "orbital_inclination": 5.14,
  "ascending_node": 125.08,
  "base_temperature": -23.0,
  "temperature_amplitude": 150.0,
  "surface_pressure": 0.0,
  "pressure_gradient": 0.0,
  "surface_y": 64
}
```

Same fields as Planet, except:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `parent_distance_km` | long | 0 | Distance from the parent planet in km. Required for fuel costs and sky scaling. |

(`orbital_distance_km` is unused for moons — set `parent_distance_km` instead.)

## 8. Texture Paths

All textures must use the full resource-location path format:

```
<namespace>:textures/space/<category>/<filename>.png
```

| Category | Path | Used for |
|----------|------|---------|
| Galaxy | `textures/space/galaxy/<id>.png` | Galaxy body in GUI |
| Star | `textures/space/star/<id>.png` | Star body in GUI and sky |
| Planet | `textures/space/planet/<id>.png` | Planet in GUI and sky |
| Moon | `textures/space/moon/<id>.png` | Moon in GUI and sky |
| Background | `textures/space/background/<id>.png` | Full-screen background in GUI |

Any `.png` under `assets/omnitech/textures/space/` is picked up automatically by the celestials atlas.

## 9. Orbital Parameters

### `orbital_radius`

Controls the visual orbit radius in the GUI orrery, in pixels at zoom = 1.0.

| Scale | Typical value |
|-------|--------------|
| Inner planet | 80–120 |
| Middle planet | 140–200 |
| Outer planet | 290–490 |
| Moon (around parent) | 70–135 |

### `orbital_speed`

A multiplier applied to the base orbital speed for GUI animation.

If `orbital_speed = 0`, the Kepler fallback is used:
```
angular_velocity = ORBIT_SPEED × (200 / orbital_radius)^1.5
```

**Suggested values:**

| Body | Suggested |
|------|-----------|
| Inner planet (fast) | 2.0 – 4.0 |
| Earth-like | 1.47 |
| Outer planet (slow) | 0.3 – 0.6 |
| Close moon | 3.0 – 5.0 |
| Distant moon | 1.5 – 2.5 |

## 10. Distance & Fuel System

### Planets: `orbital_distance_km`

The semi-major axis distance from the star, in kilometres.

| Planet | `orbital_distance_km` |
|--------|-----------------------|
| Mercury | 57,909,000 |
| Venus | 108,209,000 |
| Earth | 149,598,000 |
| Mars | 227,939,000 |
| Jupiter | 778,299,000 |
| Saturn | 1,429,394,000 |
| Uranus | 2,870,990,000 |
| Neptune | 4,498,252,000 |

### Moons: `parent_distance_km`

| Moon | Parent | `parent_distance_km` |
|------|--------|----------------------|
| Moon | Earth | 384,400 |
| Io | Jupiter | 421,700 |
| Europa | Jupiter | 671,100 |
| Ganymede | Jupiter | 1,070,400 |
| Titan | Saturn | 1,221,870 |

### Fuel Formula

```
distance_km = escape_cost + |fromStarDist − toStarDist| + entry_cost

fuel_mB     = 560 + 39 × √(distance_km / 384,400)
```

## 12. Localisation

Every `uuid` should have a corresponding translation key in `assets/omnitech/lang/en_us.json`:

```json
{
  "omnitech.space.galaxy.milky_way":  "Milky Way",
  "omnitech.space.galaxy.andromeda":  "Andromeda",
  "omnitech.space.system.sol":        "Sol",
  "omnitech.space.system.tau_ceti":   "Tau Ceti",

  "omnitech.space.body.moon":         "Moon",
  "omnitech.space.body.europa":       "Europa"
}
```

## 13. Adding a New Planet

1. Add the texture to `assets/omnitech/textures/space/planet/<uuid>.png`.

2. Create `assets/omnitech/celestial_bodies/<uuid>.json`:

```json
{
  "uuid": "kepler_22b",
  "parent": "sol",
  "type": "planet",
  "texture": "omnitech:textures/space/planet/kepler_22b.png",
  "orbital_radius": 170,
  "orbital_speed": 1.20,
  "size": 2.4,
  "orbital_distance_km": 117000000,
  "orbital_inclination": 2.80,
  "ascending_node": 90.0
}
```

3. Add a lang key: `"omnitech.space.body.kepler_22b": "Kepler-22b"`

4. If the planet has a playable dimension, set `"dimension"` to its Minecraft dimension ID.

---

## 14. Adding a New Star System

1. Add textures for the star and its background.

2. Create `assets/omnitech/celestial_bodies/<uuid>.json` with `"type": "star"` and `"parent"` set to the galaxy UUID.

3. Add planet files with `"parent": "<star_uuid>"`.

4. Add lang keys for the system and all its bodies.

---

## 15. Adding a New Galaxy

1. Create `assets/omnitech/celestial_bodies/<uuid>.json` with `"type": "galaxy"` and `"parent": "root"`.

2. Add star files with `"parent": "<galaxy_uuid>"`.

3. Add a lang key: `"omnitech.space.galaxy.<uuid>": "Display Name"`.

## 16. Full Field Reference

```
CelestialBodyDef (one per *.json file)
├── uuid                  string   (required)   unique identifier
├── parent                string   (required)   parent uuid, or "root"
├── type                  string   (required)   "galaxy" | "star" | "planet" | "moon"
├── texture               string   (required)   full resource path
├── background            string   (optional)   full resource path
├── dimension             string   (optional)   null = not implemented
├── orbital_radius        int      (default 120)
├── orbital_speed         float    (default 0 → Kepler)
├── size                  float    (default 0)
├── orbital_distance_km   long     (planets: km from star)
├── parent_distance_km    long     (moons: km from parent planet)
├── orbital_inclination   float    (default 0°)
├── ascending_node        float    (default 0°)
├── base_temperature      double   (default 20.0 °C)
├── temperature_amplitude double   (default 0.0 °C)
├── surface_pressure      double   (default 101325.0 Pa)
├── pressure_gradient     double   (default 12.0 Pa/block)
└── surface_y             int      (default 64)
```
