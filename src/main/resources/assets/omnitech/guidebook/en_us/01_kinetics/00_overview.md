# Kinetic Power

Hand-cranking machines gets tiresome fast. The kinetic power system lets you automate rotation using engines and distribute it through a network of pipes and reducers.

## Components

**Stirling Engine** — Burns solid fuel to produce steam from water, then converts that steam into kinetic energy. Your first automated power source.

**KF Generator** — Converts kinetic rotation into a speed signal that nearby machines can tap.

**KF Pipe** — Distributes kinetic force along a line. Each connection reduces torque slightly; keep networks short.

**KF Reductor** — Reduces rotation speed by a configurable ratio to match machine input requirements.

## Setup Steps

1. Place a **Stirling Engine** with water source below and fuel in front.
2. Attach a **KF Generator** to the output face.
3. Run **KF Pipes** from the generator to your machines.
4. Insert a **KF Reductor** in the pipe chain if a machine requires slower rotation.
